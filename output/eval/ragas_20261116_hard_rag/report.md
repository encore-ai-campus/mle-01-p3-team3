## 해석

- 고난도 문항은 기본 질문보다 검색 경로와 답변 구성이 복잡해 전체 점수가 낮습니다.
- 복합조회와 관계비교는 상대적으로 Faithfulness가 높아 근거를 바탕으로 답변하는 능력은 유지됩니다.
- 2단계 연결과 부분답변은 Context Precision·Answer Relevancy가 낮아 추가 개선이 필요합니다.
- Faithfulness와 Context Recall의 `n`이 전체 문항 수보다 작은 것은 RAGAS 채점 예외가 있었기 때문입니다.
